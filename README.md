# Lloyd Harold Argawanon — Portfolio

Full Stack & Backend Web Developer specializing in React, Node.js, Azure, and modern web technologies. This portfolio showcases my featured projects, technical skills, and experience building scalable web applications, cloud infrastructure, and system architecture.

## Live Site

**[https://rakuya-khun.github.io/portfolio/](https://rakuya-khun.github.io/portfolio/)**

## Tech Stack

- **React 18** — UI framework
- **TypeScript** — Type safety
- **Vite** — Build tool & dev server
- **Tailwind CSS** — Utility-first styling
- **Framer Motion** — Component animations
- **GSAP** — Scroll-triggered animations
- **Lucide React** — Icons

## Getting Started

```bash
git clone https://github.com/rakuya-khun/portfolio.git
cd portfolio
npm install
npm run dev
```

The site will be available at `http://localhost:8080`.

## Build for Production

```bash
npm run build
```

Output is generated in the `dist/` folder.

## Deployment

This project auto-deploys to GitHub Pages via GitHub Actions on every push to `main`.
